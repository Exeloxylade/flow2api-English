Connect Google Flow to Bang Story

Flow2API is a community server that uses your own Google Flow session. Start with one account and one image model.

1. Connect from Bang Story

  1. In the updated Bang Story app, open Pengaturan → Google Flow and click Hubungkan Google Flow.
  2. Wait for the first-time installation of Python, server dependencies, and Chromium. Bang Story starts the local server and manages its admin login and API key.
  3. Sign in directly with Google in the browser that opens. Complete any Google verification and continue until Google Flow opens.
  4. The session is captured automatically. This server verifies the Flow identity and adds or reconnects the account. You do not need DevTools or pasted cookies.

The matching browser-login integration requires an updated Bang Story build and this server revision. For an older local installation, stop the service and choose Pengaturan lanjutan → Pasang ulang. Accounts and settings are preserved.

2. Add or reconnect accounts

  1. Click Tambah akun Google in Bang Story to add another account with a separate browser profile.
  2. Use Hubungkan ulang if an account needs a fresh session. Sign in with the same account; a different identity is rejected.
  3. Use Hapus to remove an account and its managed login profile. Story projects are retained.

3. Try a model

A successful connection selects Google Flow for new-project images and videos. For existing projects, select the provider and models in Ide cerita. Try one image first. An account check does not generate media or prove that generation quota is available.

Google Flow eligibility, quota, verification, and browser requirements still apply. Session cookies grant account access and remain stored in your local browser and server database; do not share your data folder, exports, or credentials.
Manual account import for standalone servers (advanced)
  1. Sign in at https://flow.google.com and confirm that Flow opens for the intended account.
  2. Open browser F12 → Network, reload Flow, select its document request, and copy the full Cookie request header. JSON cookie exports containing the Google and Flow domains are also supported.
  3. In Accounts → Add, paste into Google Cookies, enter the matching email in Google Account, and save.

Complete cookies must include OSID or __Secure-OSID and Google account cookies such as SID/SAPISID. An old Session Token alone is insufficient. Standalone defaults to port 8000; Bang Story manages port 8765.

Which key goes where?

Google Cookies
Google sign-in cookies, captured automatically by Bang Story or entered in the advanced account dialog.
Flow2API API key
The key used by applications calling the server. Bang Story manages it automatically in local mode. For an external server, use its API key in Bang Story.
Admin password
Signs in to the admin panel. Bang Story manages this automatically for its local server.
Gemini API key
A separate credential for Bang Story's Gemini story or narration provider. It is not a Flow2API key.

Common problems

  • Panel is still Chinese: update Bang Story, stop the local server, click Pasang ulang, then start it again. Updating Bang Story alone does not replace an already installed server.
  • Missing or expired cookies: use Hubungkan ulang in Bang Story; standalone users can update complete cookies in the account panel.
  • Account connected but generation fails: check Google Flow access, quota, selected model, and browser/captcha status. In Bang Story local mode, the browser method is managed automatically.
  • Standalone setup: follow the English README. Use your own admin password and API key, and bind to localhost for a local installation.
