Connect Google Flow to Bang Story

Flow2API is a community server that uses your own Google Flow session. Start with one account and one image model.

1. Install and start from Bang Story

  1. Open Pengaturan → Flow2API and enable Gunakan Flow2API lokal.
  2. Click Pasang Flow2API (or Pasang ulang to update an older installation), then wait for Python, server dependencies, and Chromium to finish installing.
  3. Click Jalankan dan login, then Buka panel akun. Bang Story signs in to the local admin panel automatically.

The Bang Story server runs at http://127.0.0.1:8765. A separately installed Flow2API server normally uses port 8000.

2. Connect your Google Flow account

  1. Open https://flow.google.com in a browser and sign in to the Google account you want to use. Confirm that Flow works with that account.
  2. Press F12 → Network, reload Flow, and select the document request to flow.google.com. In Headers → Request Headers, copy the full Cookie value. A JSON cookie export containing the Flow and Google domains is also supported.
  3. Return to Accounts → Add. Paste into Google Cookies and enter the matching email in Google Account. Leave project and proxy fields empty unless you need them, then click Add.
  4. Confirm that the account appears and is enabled. If validation fails, sign in again and copy fresh, complete cookies.
This version needs complete cookies. Include a Flow session cookie (OSID or __Secure-OSID) and Google account cookies such as SID/SAPISID. An old __Secure-next-auth.session-token alone will not work. Cookies grant access to your session: paste them only into your own server and do not share them in screenshots or support messages.

3. Check the connection in Bang Story

  1. Return to Bang Story and click Periksa akun.
  2. When connected, click Gunakan untuk proyek baru. For an existing project, choose Flow2API and image/video models in Ide cerita.
  3. Try one image first. An account check does not generate media or prove that generation quota is available.

Which key goes where?

Google Cookies
Google sign-in cookies, entered in the account dialog.
Flow2API API key
The key used by applications calling the server. Bang Story manages it automatically in local mode. For an external server, use its API key in Bang Story.
Admin password
Signs in to the admin panel. Bang Story manages this automatically for its local server.
Gemini API key
A separate credential for Bang Story's Gemini story or narration provider. It is not a Flow2API key.

Common problems

  • Panel is still Chinese: update Bang Story, stop the local server, click Pasang ulang, then start it again. Updating Bang Story alone does not replace an already installed server.
  • Missing or expired cookies: sign in again, copy the complete current cookies, and edit the account.
  • Account connected but generation fails: check Google Flow access, quota, selected model, and browser/captcha status. In Bang Story local mode, the browser method is managed automatically.
  • Standalone setup: follow the English README. Use your own admin password and API key, and bind to localhost for a local installation.
